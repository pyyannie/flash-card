# Flash Card

单词闪卡学习 —— 一个纯前端的单词卡工具，零依赖、离线可用。

打开网址即用，也可以在 iPhone 上「添加到主屏幕」，像 App 一样全屏运行。

## 功能

- **制作卡片**：手动输入，或导入 CSV / TSV / TXT
- **翻卡复习**：点击翻面，正面单词 + 音标，背面词性 + 释义 + 例句
- **自动播放**：可调速（慢 5 秒 / 中 3 秒 / 快 1.5 秒），播完一轮自动循环，支持暂停与停止
- **朗读**：三档切换 —— 不读 / 只读英文 / 英文 + 中文释义
- **生词本**：收藏重点单词，可单独复习、单独导出
- **卡片管理**：编辑、删除、按导入顺序或 A→Z 排序
- **导出 CSV**：带「收藏」列，重新导入时生词本会自动恢复

## 导入格式

表头怎么写都行，只要看得出意思：

```csv
单词,音标,中文释义,词性,例句,收藏
mead,/miːd/,蜂蜜酒,n.,,是
apparently,/əˈpærəntli/,看样子、似乎,adv.,,
```

- 中英文表头都认（`单词` / `word`、`中文释义` / `meaning` 等）
- 用不上的列（如「序号」）自动忽略
- 没有表头时，默认第一列是单词、第二列是释义
- 重复的单词自动跳过
- Excel 文件请先「另存为 CSV」

## 多设备同步

手机和电脑可以共用一份单词库，数据存在**你自己的私密 Gist** 里：

1. 首页点「☁️ 开启同步」
2. 到 [github.com/settings/tokens/new](https://github.com/settings/tokens/new) 生成一个 **classic** token，Expiration 选 No expiration，scopes **只勾 `gist`**
3. 把 token 填进去，点「连接」
4. 另一台设备填**同一串 token** 即可，不需要记 Gist 编号

同步策略是**合并**：两边的卡片都保留，同一个单词不重复，空着的字段会从另一边补齐，所以不会丢词。删除不会跨设备传播 —— 需要时用「强制上传 / 强制下载」。

改动会在几秒后自动上传，打开页面时自动拉取。

## 数据存在哪

默认全部存在浏览器本地（localStorage），不经过任何第三方服务器。开启同步后会额外存一份到你自己的私密 Gist。

token 只保存在各设备的浏览器里，不在源码中，所以本仓库公开也不影响安全。

建议定期用「导出 CSV」再备份一份 —— 那是唯一不依赖浏览器的副本。
